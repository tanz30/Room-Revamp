# RoomRevamp — Interior Design & Furniture Placement Assistant

## 📌 Overview
**RoomRevamp** is a lightweight, intuitive room planning and layout optimization tool. Designed for effortless interior arrangement, it enables users to input room specifications, customize wall colors, place furniture items visually, and instantly analyze spatial metrics like available floor space and collision detection.

## ✨ Key Features
* **Custom Room Setup:** Define custom room lengths, widths, and background wall colors.
* **Interactive Drag-and-Drop:** Fluidly position and rearrange furniture items (Beds, Tables, Sofas, Wardrobes, and Chairs) within room boundaries.
* **Overlap Detection:** Real-time AABB collision checks to warn users if furniture items intersect.
* **Space Utilization Analytics:** Calculates total room area, occupied area, and open floor space in square meters ($m^2$).
* **Rule-Based Layout Suggestions:** Instant feedback on whether a room's space utilization is balanced or overcrowded.
